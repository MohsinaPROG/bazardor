# 🛒 বাজার দর (BazarDor)

## Short Description

BazarDor is a responsive web application that shows the daily prices of essential goods in Bangladesh, including rice, lentils, oil, vegetables, fish, meat, and eggs. Users can see today's price, the change from yesterday, and the minimum, maximum, and average prices across different markets. Signing in is required to view product details.

## Technologies Used

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- Better Auth
- MongoDB
- react-hot-toast
- REST API
- Git & GitHub

## Key Features

- Price ticker below the navbar that scrolls today's prices and changes
- Top 6 price risers and top 6 price fallers on the home page
- Category pages with sorting by price (low to high / high to low)
- Product detail page with min, max, and average prices and a market-wise price table
- Sign up, sign in, Google and GitHub login, and profile name update
